# Fibery Process Cookbook

Open recipes for how teams, companies and communities run their work, from Shape Up and OKRs to a phone repair shop or a CS2 team. A recipe is a process in plain words that a person can run it from, with the model a builder needs to set it up in any tool. Copy, adapt and build any of them, crediting the cookbook.

## Use a recipe

- **In Fibery:** add the Fibery plugin from [Fibery-inc/skills](https://github.com/Fibery-inc/skills) to your AI agent and name the process ("set up OKRs"): it finds the recipe here by itself, or uses one you attach or link. You see a one-screen design first, and nothing is created until you say yes.
- **Anywhere else:** give the recipe to your AI assistant and name your tool, or build it by hand from its Details for building.

## What's in a recipe

The first half is for the people who run the process: the idea, one example followed through its whole life, what people look at and when, the rules that run by themselves, what must stay true and what keeps it so, and the questions to decide before setting it up. The second half, Details for building, is for the builder: the records, fields, states, formulas, views, rules and a sample story. Sources lists the one to three published sources the recipe was written from. [FORMAT.md](FORMAT.md) is the full format.
